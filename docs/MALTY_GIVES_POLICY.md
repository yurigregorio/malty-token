# MALTY Gives / MALTY Impact — Policy Draft

Status: **Planned initiative — not active**

MALTY Gives is the project's planned social-impact initiative focused on animal welfare. `MALTY Impact` is the dedicated token reserve and public wallet intended to support that initiative. The program is intentionally separate from token price, trading activity and investment expectations.

## MALTY Impact Reserve

The canonical tokenomics allocate **50,000,000 MALTY (5% of the fixed 1,000,000,000 MALTY supply)** to the MALTY Impact Reserve.

- **Reserve label:** `MALTY Impact`
- **Public wallet:** `DmPEyGFwy972wcdcA7UzxtDiSdrtU3Y4UJned7AJJyik`
- **Allocation:** 50,000,000 MALTY
- **Share of total supply:** 5%
- **Planned initial circulating availability:** 0 MALTY
- **Program status:** planned / not active

Funding the MALTY Impact wallet is a reserve allocation, **not a donation by itself**. Tokens only become part of a completed impact action when a documented initiative is actually executed according to this policy.

## Principles

1. **No promise before an initiative is approved.** The reserve exists for future animal-welfare initiatives, but MALTY does not promise a fixed fiat donation amount, transaction-tax donation, recurring contribution or guaranteed cadence.
2. **Organizations must be identifiable.** A supported organization or project should have a verifiable identity and a clear animal-welfare purpose.
3. **Contributions must be evidenced.** When an initiative occurs, MALTY should publish the beneficiary, purpose, date, contribution amount or goods, status and suitable proof of completion.
4. **On-chain claims must be verifiable.** If MALTY or other blockchain assets are moved as part of an initiative, the relevant public transaction should be referenced where appropriate.
5. **Privacy comes first.** Public evidence must not expose private donor, volunteer, employee or beneficiary information unnecessarily.
6. **No performance marketing.** MALTY Gives / MALTY Impact must not be presented as a reason to expect token price appreciation, returns or guaranteed demand.
7. **Reserve movements are accountable.** Every material movement from the MALTY Impact Reserve should have a documented purpose and be reconciled against the public wallet.

## Activation checklist

Before MALTY Gives changes from **Planned** to **Active**, the project should publish:

- the operating funding model for each initiative;
- eligibility and selection criteria;
- the first identified beneficiary or initiative;
- the evidence format used for completed contributions;
- the responsible project process for reviewing and publishing each initiative;
- the role, if any, of community voting or governance.

## Public reporting model

For each completed initiative, publish a concise record containing:

| Field | Required |
| --- | --- |
| Beneficiary / organization | Yes |
| Purpose | Yes |
| Date | Yes |
| Contribution amount or goods | Yes |
| Status | Yes |
| Evidence / receipt when appropriate | Yes |
| Blockchain transaction when applicable | Yes |

## Reserve handling

The 50M allocation is intended to remain reserved until documented impact initiatives are approved. Simply moving the allocation from the project wallet into the MALTY Impact wallet does not make it circulating supply and does not count as an animal-welfare contribution.

If MALTY tokens are later sold, swapped or otherwise used to fund an initiative, the project should clearly document the relevant movement and avoid describing a fiat value as guaranteed before execution.

## Current state

The MALTY Impact Reserve is now part of the canonical tokenomics. The MALTY Gives contribution program itself remains **planned and not active**. No completed animal-welfare contribution should be claimed until an initiative is actually executed and evidenced.
