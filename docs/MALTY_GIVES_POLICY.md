# MALTY Gives — Policy Draft

Status: **Planned initiative — not active**

MALTY Gives is the project's planned social-impact initiative focused on animal welfare. It is intentionally separate from token price, trading activity and investment expectations.

## Principles

1. **No promise before funding exists.** MALTY does not currently promise a fixed donation amount, percentage of revenue, percentage of token transactions or recurring contribution.
2. **Organizations must be identifiable.** A supported organization or project should have a verifiable identity and a clear animal-welfare purpose.
3. **Contributions must be evidenced.** When an initiative occurs, MALTY should publish the beneficiary, purpose, date, amount or goods contributed, and suitable proof of completion.
4. **On-chain claims must be verifiable.** If a contribution uses blockchain funds, the relevant public transaction should be referenced where appropriate.
5. **Privacy comes first.** Public evidence must not expose private donor, volunteer, employee or beneficiary information unnecessarily.
6. **No performance marketing.** MALTY Gives must not be presented as a reason to expect token price appreciation, returns or guaranteed demand.

## Activation checklist

Before MALTY Gives changes from **Planned** to **Active**, the project should publish:

- the funding model;
- eligibility and selection criteria;
- the first identified beneficiary or initiative;
- the evidence format used for completed contributions;
- the responsible project process for reviewing and publishing each initiative.

## Public reporting model

For each completed initiative, publish a concise record containing:

| Field | Required |
| --- | --- |
| Beneficiary / organization | Yes |
| Purpose | Yes |
| Date | Yes |
| Contribution amount or goods | Yes |
| Status | Yes |
| Evidence / receipt when appropriate | Yes |
| Blockchain transaction when applicable | Yes |
